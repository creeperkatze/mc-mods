# Changelog

## [Unreleased]

### Added

- Backported to Minecraft 1.21.1.
- Banner in the NeoForge mod list.
- German translation.
- Option to light OpenRGB devices from the layout of the OpenRGB Visual Map plugin.
- Hyperion and HyperHDR support.

### Changed

- Works with older Fabric Loader and NeoForge versions instead of only the newest ones.
- The flicker warning only shows when SignalRGB and OpenRGB are both connected.
- Settings with several choices now explain every choice at once.
- The device settings show an icon for each app and a colored dot for its status.

### Fixed

- The SignalRGB and OpenRGB status now shows the correct state.
